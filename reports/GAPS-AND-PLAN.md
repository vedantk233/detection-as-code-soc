# Priority Gaps and Quarterly Purple-Team Plan

## Top three gaps
1. Required detection coverage, tuning, correlation and enrichment: validate rules against the project guide and add missing scenarios.
2. End-to-end response: implement alert targets, evidence collection, notification and genuine human approval before containment.
3. Verified effectiveness: test in a dedicated sandbox, record detection/playbook timings and cleanup, then update the dashboard and ATT&CK layer.

## Quarterly plan
- Month 1: review detection logic, owners, allow-lists and false-positive estimates.
- Month 2: run approved sandbox simulations; record alerts, response timing and cleanup.
- Month 3: remediate failed detections, review ATT&CK gaps and repeat regression tests.

All attack simulation requires an approved dedicated sandbox, budget controls and cleanup verification.
